## 🎓 学习路径

### 🚀 快速入门（1-2 天）

如果你是 Git 新手，建议按以下顺序学习：

```
第一天：理解 Git 核心概念
├─ 01. 初识 Git          → 了解版本控制
├─ 02. Git 的特性        → 理解 Git 优势
├─ 03. 使用 Git 的方式   → 选择适合的工具
├─ 04. 安装 Git          → 配置开发环境
├─ 05. 初始配置          → 设置用户信息
├─ 06. 创建本地仓库      → 掌握三大区域（工作区、暂存区、版本库）
├─ 07. 更新文件并提交    → 第一次提交
└─ 08. 查看提交历史      → 理解提交记录

第二天：掌握基本操作
├─ 10. 切换版本          → 时光穿梭
├─ 12. 撤销未暂存修改    → 后悔药
├─ 13. 撤销已暂存修改    → 撤回操作
├─ 18. 忽略文件          → .gitignore
├─ 20. 创建分支          → 分支基础
└─ 21. 合并分支          → 基本合并
```

**学习成果**：能够在本地使用 Git 管理代码，掌握基本的提交、分支、合并操作。

### 📈 进阶提升（3-5 天）

掌握基础后，学习团队协作和高级操作：

```
远程协作篇
├─ 27. 多存储库           → 远程仓库概念
├─ 28. 从原始仓库获取更改 → git fetch
├─ 29. 合并远程更改       → 整合远程代码
├─ 30. 拉取与集成         → git pull
├─ 31. 创建跟踪分支       → 本地与远程关联
├─ 33. 推送变更           → git push
└─ 35. 托管 Git 仓库      → GitHub/GitLab

分支与合并篇
├─ 22. 解决合并冲突       → 冲突处理
├─ 23. 撤销合并           → 合并后悔
├─ 24. 变基与合并         → rebase vs merge
├─ 25. 使用变基整理分支   → 整理提交历史
└─ 26. 合并到主分支       → 规范流程

撤销与修正篇
├─ 14. 还原已提交修改     → git revert
├─ 15. 从分支中删除提交   → git reset
├─ 16. 修改最近提交       → git commit --amend
└─ 38. 撤销操作指南       → 撤销操作总结
```

**学习成果**：能够参与团队协作，处理复杂的分支合并场景，掌握各种撤销操作。

### 🎖️ 高级精通（1-2 周）

深入学习高级特性和最佳实践：

```
高级篇
├─ 01. 交互式暂存与提交整理  → git add -i
├─ 02. 储藏与多工作树        → git stash / worktree
├─ 03. 挑选提交与定位问题    → git cherry-pick / bisect
├─ 04. 安全地改写历史        → git rebase -i
├─ 05. 子模块                → git submodule
├─ 06. 钩子与自动化          → Git Hooks
└─ 07. 仓库清理与敏感信息处理 → 清理大文件

协作工作流
├─ 40. 认证与传输协议        → SSH/HTTPS
├─ 41. 跨平台文本与属性      → .gitattributes
├─ 42. 协作工作流            → Git Flow / GitHub Flow
└─ GitHub/GitLab 篇          → 平台特性

实战案例
└─ 分支落后时的合并策略      → 真实案例分析
```

**学习成果**：成为 Git 高手，能够处理各种复杂场景，建立团队工作流规范。

## 📝 学习建议

### ✅ 推荐做法

1. **动手实践**：每个章节都包含实验，请务必亲自操作
2. **做好笔记**：记录关键命令和个人理解
3. **反复练习**：重要命令多练几遍，形成肌肉记忆
4. **建立项目**：创建测试仓库，尝试各种操作
5. **参考官方文档**：遇到问题查阅 [Pro Git](https://git-scm.com/book/zh/v2)

### ❌ 常见误区

1. **只看不练**：看懂和会用是两回事
2. **跳过基础**：没有扎实的基础，后续学习会很吃力
3. **畏惧命令行**：命令行才是 Git 的精髓
4. **不理解原理**：理解 Git 的工作原理比记住命令更重要
5. **害怕出错**：在测试仓库中大胆尝试，犯错是最好的学习方式

## 🎯 命令速查

### 常用命令

```bash
# 配置
git config --global user.name "Your Name"
git config --global user.email "email@example.com"

# 基础操作
git init                      # 初始化仓库
git add <file>                # 添加到暂存区
git commit -m "message"       # 提交
git status                    # 查看状态
git log                       # 查看历史

# 分支操作
git branch <name>             # 创建分支
git checkout <name>           # 切换分支
git merge <branch>            # 合并分支
git branch -d <name>          # 删除分支

# 远程操作
git clone <url>               # 克隆仓库
git pull                      # 拉取并合并
git push                      # 推送到远程
git remote -v                 # 查看远程仓库

# 撤销操作
git checkout -- <file>        # 撤销工作区修改
git reset HEAD <file>         # 撤销暂存
git revert <commit>           # 撤销提交
```

> 💡 完整命令列表请查看各章节详细说明。
