# 03.挑选提交与定位问题

## 挑选单个提交

`cherry-pick` 把指定提交的更改应用到当前分支，并创建一个新提交：

```powershell
git switch release
git cherry-pick <commit>
```

发生冲突时：

```powershell
git status
# 编辑并解决冲突
git add <files>
git cherry-pick --continue
```

放弃操作使用 `git cherry-pick --abort`。它适合把独立修复迁移到发布分支，不适合代替正常的分支合并。

## 二分定位错误

已知一个正常提交和一个异常提交时，`bisect` 使用二分搜索定位首次引入问题的提交：

```powershell
git bisect start
git bisect bad
git bisect good <known-good-commit>
```

Git 每次检出一个中间提交。测试后标记：

```powershell
git bisect good
# 或
git bisect bad
```

找到结果后恢复原状态：

```powershell
git bisect reset
```

如果测试可以用一个返回成功或失败状态的命令表示，可以自动执行：

```powershell
git bisect run <test-command>
```
