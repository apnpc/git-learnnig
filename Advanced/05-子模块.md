# 05.子模块

子模块让一个仓库记录另一个仓库的特定提交。它适合需要独立版本和权限边界的外部项目；同一项目内可直接复制或由包管理器解决的问题，不要使用子模块。

## 添加和克隆

```powershell
git submodule add https://example.com/library.git libs/library
git commit -m "Add library submodule"
```

主仓库记录的是子模块提交，而不是其文件内容。克隆包含子模块的项目：

```powershell
git clone --recurse-submodules <url>
```

已经克隆后初始化：

```powershell
git submodule update --init --recursive
```

## 更新子模块

```powershell
git -C libs/library fetch
git -C libs/library switch <branch>
git -C libs/library pull --ff-only
git add libs/library
git commit -m "Update library submodule"
```

最后两步提交的是主仓库中的子模块指针更新。切换主仓库分支后，运行 `git submodule update --init --recursive` 使工作目录匹配记录的提交。

删除子模块涉及 `.gitmodules`、索引和模块元数据，不要只删除目录。
