# 06.钩子与自动化

Git 钩子是在特定事件发生时运行的脚本，模板位于 `.git/hooks/`。常见本地钩子包括：

- `pre-commit`：创建提交前检查暂存内容；
- `commit-msg`：检查提交信息；
- `pre-push`：推送前执行检查。

例如 `.git/hooks/pre-commit`：

```sh
#!/bin/sh
exec git diff --cached --check
```

脚本需要可执行权限：

```powershell
git update-index --chmod=+x .githooks/pre-commit
git config core.hooksPath .githooks
```

`.git/hooks/` 默认不会提交。团队共享钩子时，可以把脚本放进 `.githooks/` 并配置 `core.hooksPath`；配置本身仍需要每位成员执行一次。

客户端钩子可以被跳过，不能作为唯一的安全或质量边界。必须执行的检查应同时放到持续集成或服务端保护规则中。
