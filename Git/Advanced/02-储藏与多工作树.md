# 02.储藏与多工作树

## 临时储藏修改

需要临时切换任务，但当前修改还不适合提交时：

```powershell
git stash push -u -m "login work in progress"
git stash list
git stash show -p stash@{0}
git stash pop
```

- `-u` 同时储藏未跟踪文件；
- `pop` 应用成功后删除储藏；
- `apply` 应用后保留储藏；
- 被忽略的文件默认不会进入 stash。

stash 适合短期切换，不应长期代替提交。

## 同时检出多个分支

`worktree` 允许同一仓库同时拥有多个工作目录：

```powershell
git worktree add ../hotfix -b hotfix main
git worktree list
```

现在可以在当前目录继续开发，同时在 `../hotfix` 修复问题。完成后：

```powershell
git worktree remove ../hotfix
git branch -d hotfix
```

同一个普通分支不能同时检出到两个工作树。不要直接删除工作树目录，应使用 `git worktree remove`，否则需要再运行 `git worktree prune` 清理记录。
