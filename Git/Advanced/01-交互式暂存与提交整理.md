# 01.交互式暂存与提交整理

一个文件可能同时包含多个不相关修改。交互式暂存可以只提交其中一部分：

```powershell
git add -p
git diff --staged
git commit -m "Fix validation"
```

常用选择：

- `y`：暂存当前块；
- `n`：跳过当前块；
- `s`：尝试把当前块拆得更小；
- `e`：手动编辑补丁；
- `q`：退出。

## 整理尚未共享的提交

```powershell
git branch backup/before-rebase
git rebase -i HEAD~4
```

交互式 rebase 常用动作：

- `reword`：修改提交信息；
- `edit`：暂停并修改提交；
- `squash`：合并到前一个提交并编辑说明；
- `fixup`：合并到前一个提交并丢弃当前说明；
- `drop`：删除提交。

修改完成后：

```powershell
git rebase --continue
```

放弃整个过程：

```powershell
git rebase --abort
```

rebase 会创建新提交并改变哈希。不要对共享分支执行交互式 rebase。
