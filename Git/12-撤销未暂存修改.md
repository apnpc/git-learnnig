# 12.撤销修改-本地已保存状态

本节将学习如何恢复暂存前的更改，也就是在工作区下已经修改保存，还未暂存的文件。

每次操作前，使用 `git status` 确认当前分支和工作区状态。如果不在本实验使用的主分支上，使用 `git switch master` 切换。

## 修改文件

在 test 文件中添加一行 123，并保存。

```powershell
# 查看文件内容
$ cat .\test.txt
abc
123
```

## 恢复本地修改

现在恢复未暂存的修改。现代 Git 推荐使用职责明确的 `restore` 命令：

```powershell
# 恢复
$ git restore test.txt

$ cat .\test.txt
abc
```
