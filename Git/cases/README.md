# Git 实战案例集

本目录收录了真实项目中遇到的 Git 使用场景和解决方案，帮助你在实际工作中更好地应用 Git。

## 案例列表

### [01. 分支落后时的合并策略](01-分支落后时的合并策略.md)

**场景**：工作分支基于旧版本进行了改进，而主分支已经进行了大规模重构，如何安全地合并？

**涵盖知识点**：
- 分支合并策略
- 冲突解决技巧
- 文件重命名处理
- 保留重要改进
- 合并提交的编写

**难度**：⭐⭐⭐⭐ 高级

**适合读者**：
- 需要处理复杂合并场景的开发者
- 团队协作中遇到分支冲突的情况
- 希望深入理解 Git 合并机制的学习者
