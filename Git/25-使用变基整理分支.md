# 25.使用变基整理分支

假设 `master` 和 `lgnew` 已经产生不同提交。先查看关系：

```powershell
git log --oneline --graph --decorate --all
```

## 创建安全引用

本实验会改写 `lgnew` 的提交。先确保工作区干净，并创建备份分支：

```powershell
git status
git switch lgnew
git branch backup/lgnew-before-rebase
```

## 执行变基

```powershell
git rebase master
```

Git 会找到 `lgnew` 相对 `master` 独有的提交，再把它们重新应用到 `master` 顶部。提交哈希会改变。

发生冲突时：

```powershell
git status
# 编辑冲突文件
git add <file>
git rebase --continue
```

放弃整个变基：

```powershell
git rebase --abort
```

## 快进主分支

变基成功后，`lgnew` 位于 `master` 前方，可以快进合并：

```powershell
git switch master
git merge --ff-only lgnew
```

只有尚未共享的个人分支适合这样整理。不要重写其他人已经依赖的提交。
